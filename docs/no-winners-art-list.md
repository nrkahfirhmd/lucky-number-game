# No Winners: Art List

Everything that needs art for the first-person desk version, based on [desk.html](../prototypes/desk.html). **Art is chosen: Teletext room, Marquee screens** (see [art direction](no-winners-art-direction.md)). Game mode isn't chosen yet, so this list flags what depends on it.

**Priority**
- **Must:** the game doesn't work or read without it.
- **Should:** expected in a finished jam game.
- **Could:** only if time allows.

**Size** is a rough guess at effort, not a measured estimate: S is under an hour, M is a few hours, L is most of a day.

**In POC** means a placeholder exists in `desk.html`. Those show what's needed, but they aren't final art.

## Not on this list

- **Audio:** the design docs call for sound in Milestone 3, so it needs its own list.
- **Writing:** headlines, slogans and show patter are a big part of the comedy, and need time set aside.

## First pieces to make

Art is chosen, so start with these:

1. CRT monitor and desk, because they're on screen all the time.
2. Big button and card or tile template, because they're what the player touches.
3. Broadcast, because it's the payoff.
4. Room lighting, which can make simple models look finished.
